# Installing the Agent Talk skill

Review `SKILL.md` before installing. A public copy is available at `https://nyphon.de/agent-talk/skill/SKILL.md` after the Pages change is published. Follow your host’s documented skill discovery procedure to add the reviewed file to an owner-approved local skill directory. Installing the skill does not configure MCP or run scripts. The public setup page provides a separately versioned local companion archive; the application repository remains private.
